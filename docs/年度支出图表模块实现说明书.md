# 年度支出图表模块实现说明书

## 1. 功能需求

### 1.1 核心功能
- 在仪表盘页面添加年度支出趋势图表
- 支持年份筛选，默认显示当前年份
- 展示选定年份1月1日至12月31日的完整支出数据
- 提供清晰直观的图表样式

### 1.2 用户交互
- 年份选择器：下拉选择框，支持选择不同年份
- 图表展示：折线图或柱状图展示月度支出趋势
- 数据加载：支持异步加载和错误处理

## 2. 技术选型

### 2.1 前端技术
- **图表库**: Ant Design Charts (基于G2Plot)
  - 理由：与现有Ant Design UI库完美集成
  - 提供丰富的图表类型和配置选项
  - 支持响应式设计和主题定制

- **状态管理**: React Hooks (useState, useEffect)
  - 理由：图表数据相对独立，无需复杂状态管理
  - 与现有代码风格保持一致

- **API调用**: 现有的API服务层
  - 复用BillService或创建新的ChartService

### 2.2 后端技术
- **数据库查询**: SQLAlchemy ORM
- **数据聚合**: SQL GROUP BY 按月份聚合
- **API框架**: FastAPI (现有框架)

## 3. 数据库设计

### 3.1 现有表结构
使用现有的bills表，主要字段：
- `transaction_date`: 交易日期
- `amount`: 金额
- `transaction_type`: 交易类型 (income/expense)
- `user_id`: 用户ID

### 3.2 查询逻辑
```sql
SELECT 
    EXTRACT(MONTH FROM transaction_date) as month,
    SUM(amount) as total_expense
FROM bills 
WHERE 
    transaction_type = 'expense' 
    AND EXTRACT(YEAR FROM transaction_date) = :year
    AND user_id = :user_id
GROUP BY EXTRACT(MONTH FROM transaction_date)
ORDER BY month;
```

## 4. API设计

### 4.1 新增接口
**接口路径**: `GET /api/bills/yearly-expense-chart`

**请求参数**:
```json
{
    "year": 2024  // 可选，默认当前年份
}
```

**响应格式**:
```json
{
    "success": true,
    "data": {
        "year": 2024,
        "monthly_expenses": [
            {"month": 1, "amount": 5000.00, "month_name": "1月"},
            {"month": 2, "amount": 4500.00, "month_name": "2月"},
            // ... 12个月的数据
        ],
        "total_year_expense": 60000.00
    }
}
```

### 4.2 错误处理
- 参数验证：年份范围检查
- 权限验证：用户身份验证
- 数据异常：空数据处理
