### 数据库结构
```sql
-- users表新增字段
ALTER TABLE users ADD COLUMN is_admin BOOLEAN DEFAULT FALSE;
UPDATE users SET is_admin = TRUE WHERE username = 'test';
```

### API认证流程
1. 用户通过 `/api/v1/auth/login` 登录
2. 服务器返回JWT访问令牌
3. 后续请求需要在Header中包含: `Authorization: Bearer <token>`
4. 服务器验证令牌和用户权限

### 权限控制
- 所有用户管理API都需要管理员权限 (`is_admin = TRUE`)
- 使用装饰器或中间件进行权限检查
- 非管理员用户访问时返回401或403错误
